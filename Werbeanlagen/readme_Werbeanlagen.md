# Werbeanlagen
## Allgemein
Dieses Verzeichnis enthält Modelle von Werbetafeln und Litfaßsäulen.

## Grundlage
Als Grundlage für die zur Verfügung gestellten Modelle dienen **Fotos** und **Produktskizzen/-maße** der jeweiligen Realweltobjekte.
